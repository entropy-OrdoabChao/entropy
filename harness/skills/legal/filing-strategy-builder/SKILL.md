# Filing Strategy Builder

## Overview

The sequence of filings matters. A motion to strike filed before a motion
to dismiss may be premature. A motion for summary judgment filed before
discovery may be denied. This skill determines the optimal sequence.

## Workflow

### Step 1: Query the corpus for the filing type + sequence

    GET http://localhost:8100/search_text?query=FILING+TYPE+sequence+order&top_k=10

### Step 2: Cross-reference with Beezle MCP

- `mcp_beezle_recommend_filing_types` — score filing types against the case's
  defect profile
- `mcp_beezle_compose_recommend` — recommend filing types for a case based on
  audit defects
- `mcp_beezle_deadline_rules` — list all available deadline rules

### Step 3: Build the strategy

For each filing, document:
- The filing type
- The sequence (when to file it)
- The rationale (why file it now)
- The remedy (what you are seeking)

## Key patterns

### Sequence patterns

- Motion to dismiss before motion to strike
- Motion to compel before motion for summary judgment
- Motion for reconsideration before appeal
- Appeal before mandate

### Filing type patterns

- Motion to strike: when opposing counsel files with procedural defects
- Motion to dismiss: when the complaint fails to state a claim
- Motion for summary judgment: when there is no genuine dispute of material
  fact
- Motion for reconsideration: when the court made an error of law
- Appeal: when the court's final order is wrong

## Example: FCRA case with 93 fatal violations

1. GET /search_text?query=FCRA motion to strike sequence order
2. Cross-reference with Beezle MCP case audits
3. Document strategy: File motion to strike first (14 MTDs with 93 fatal
   violations), then motion for summary judgment, then appeal
4. Rationale: Motion to strike eliminates the defective filings first,
   then motion for summary judgment can be based on the remaining record

## Pitfalls

- Don't file in the wrong order — verify the sequence
- Don't file before discovery — verify the record is complete
- Don't file before a deadline — verify the deadline
- When in doubt, query the corpus directly rather than relying on MCP tool
  defaults
