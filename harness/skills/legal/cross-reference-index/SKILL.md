# Cross-Reference Index

## Overview

The cross-reference index is the master index that links everything together —
statutes, remedies, definitions, and cases. It's the "search engine" for the
Obsidian graph.

## Data Source

The index lives at:
`/home/{{USER_FIRST}}/.hermes/skills/legal/cross-reference-index/data/cross_reference_index.json`

It contains:
- **statutes**: statutes with their remedies, definitions, related statutes, and key cases
- **definitions**: definitions with their statute, related definitions, and source
- **remedies**: remedies with their statute, type, amount, and related remedies
- **cases**: cases with their court, year, statutes, remedies, and binding status

## Usage

### Find remedies for a statute

1. Load the index: `read_file /home/{{USER_FIRST}}/.hermes/skills/legal/cross-reference-index/data/cross_reference_index.json`
2. Look up the statute: `statutes["15 USC 1681"]`
3. Get the remedies: `statutes["15 USC 1681"]["remedies"]`

### Find related definitions for a term

1. Load the index
2. Look up the definition: `definitions["furnisher"]`
3. Get the related definitions: `definitions["furnisher"]["related_definitions"]`

### Find related remedies for a remedy

1. Load the index
2. Look up the remedy: `remedies["15 USC 1681_damages"]`
3. Get the related remedies: `remedies["15 USC 1681_damages"]["related_remedies"]`

### Find cases for a statute

1. Load the index
2. Look up the statute: `statutes["15 USC 1681"]`
3. Get the key cases: `statutes["15 USC 1681"]["key_cases"]`

## Workflow

### Step 1: Query the index for related knowledge

Load the index and look up the statute, term, or citation you're researching.

### Step 2: Query the corpus for gaps

If the index doesn't have the answer, query the corpus:
    GET http://localhost:8100/search_text?query=QUERY&top_k=10

### Step 3: Update the index

If the corpus has something the index doesn't have, update the index:
    write_file /home/{{USER_FIRST}}/.hermes/skills/legal/cross-reference-index/data/cross_reference_index.json

## Pitfalls

- Don't assume the index has everything — verify against the corpus
- Don't assume the index is up to date — check the last_updated field
- Don't assume a case is binding — verify the binding_on field
- Don't assume a remedy is mandatory — verify the mandatory field
