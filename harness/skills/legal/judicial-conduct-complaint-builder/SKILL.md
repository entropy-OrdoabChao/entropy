# Judicial Conduct Complaint Builder

## Overview

Judges can be disciplined for violations of judicial conduct rules. This skill
builds those complaints for the appropriate judicial conduct body.

## Legal Framework

### Federal Judicial Conduct (28 U.S.C. 372)

Under 28 U.S.C. 372, complaints against federal judges are filed with the
Circuit Judicial Council. The Council investigates and may recommend discipline.

### PA Judicial Conduct (Pa. Code 204-1)

Under Pa. Code 204-1, complaints against PA judges are filed with the
Judicial Conduct Board. The Board investigates and may recommend discipline.

### Grounds for Complaint

- Misconduct in office
- Persistent failure to perform judicial duties
- Incapacity or unfitness
- Engaging in conduct prejudicial to the administration of justice

## Workflow

### Step 1: Gather case data via Beezle MCP

- mcp_beezle_case_audit_summary — get case details (judge, court, parties)
- mcp_beezle_get_case_score — get scorecard summary for the case
- mcp_beezle_get_case_violations — get flagged violations for the case
- mcp_beezle_case_audit_summary — get audit findings for the case
- mcp_beezle_case_diagnose — get full case diagnosis
- mcp_beezle_analyze_immunity — analyze immunity status for the judge

### Step 2: Classify violations

For each violation, classify by:
- Judicial misconduct (Canon violations, bias, overreach)
- Due process violations (Mathews prongs)
- Stare decisis violations (non-binding authority as controlling)
- Procedural violations (FRCP/local rules)
- Bias indicators (emotional language, punitive appeals)

### Step 3: Build the complaint

For each violation, document:
- The judge (who violated the rules)
- The violation (what the judge did wrong)
- The evidence (what documents or orders show the violation)
- The applicable rule (which judicial conduct rule was violated)
- The requested relief (what discipline is sought)

### Step 4: Write to Obsidian

Write the complaint to Obsidian:
    write_obsidian_note(subdir=SUBDIR, filename=FILENAME, content=CONTENT)

### Add wikilinks

Add wikilinks to the complaint:
    obsidian_propose_link(from_note=COMPLAINT_NOTE, to_note=CASE_NOTE, edge_type=authority, citation=CITATION)

## Key patterns

### Federal complaint

1. Get case data: mcp_beezle_case_audit_summary + mcp_beezle_case_audit_summary for the case
2. Analyze immunity: mcp_beezle_analyze_immunity (defendant_type="judge")
3. Document each violation with evidence
4. Build the complaint: File with the Circuit Judicial Council
5. Write to Obsidian: judicial_conduct_complaint_federal_JUDGE_NAME.md

### PA complaint

1. Get case data: mcp_beezle_case_audit_summary + mcp_beezle_case_audit_summary for the case
2. Analyze immunity: mcp_beezle_analyze_immunity (defendant_type="judge")
3. Document each violation with evidence
4. Build the complaint: File with the Judicial Conduct Board
5. Write to Obsidian: judicial_conduct_complaint_PA_JUDGE_NAME.md

## Pitfalls

- Don't file a complaint without documenting the violation
- Don't file a complaint without documenting the evidence
- Don't file a complaint without documenting the applicable rule
- Don't file a complaint without documenting the requested relief
- Don't file a complaint without verifying the jurisdiction
