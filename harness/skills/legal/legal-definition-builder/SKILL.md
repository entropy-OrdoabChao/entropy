# Legal Definition Builder

## Overview

The same word can mean different things in different statutes. This skill
ensures definitions are tied to the correct statute and context.

## Workflow

### Step 1: Query the corpus for the term

    GET http://localhost:8100/lookup_term?term=TERM&max_hits=10

This returns all occurrences of the term across the corpus.

### Step 2: Filter by statute scope

From the hits, identify which ones are tied to the specific statute you care about.
Look at the `source` field and `metadata` to find statute-specific definitions.

### Step 3: Cross-reference with MCP tools

Use Beezle MCP tools to validate and expand:
- `definition_lookup` — structured definition lookup
- `build_definitions` — locked legal definition set for a legal issue
- `discover_case_type` — find applicable statutes and definitions

### Step 4: Resolve conflicts

If the corpus definition conflicts with an MCP tool definition, investigate:
- Is the corpus definition from a different statute?
- Is the MCP tool definition outdated?
- Is there a more specific definition in the corpus?

## Key patterns

### Closed vs. expansive definitions

- "means" = closed definition (only what is listed)
- "includes" = expansive definition (what is listed plus similar items)

### Statutory definition cross-references

- Check if the statute references another statute for a definition
- The definition may be in a different title/section — follow the cross-ref

### Regulatory definitions

- CFR definitions may expand or narrow USC definitions
- Always check the implementing regulation

## Example: "furnisher" under FCRA

1. GET /lookup_term?term=furnisher — find all corpus occurrences
2. Filter to 15 USC 1681 context
3. Validate with `definition_lookup(term="furnisher", statute_scope="15 USC 1681")`
4. Check Regulation V (12 CFR Part 571) for additional definitions

## Pitfalls

- Don't accept the first definition — verify it applies to the specific statute
- Don't assume the corpus has every definition — it may be missing
- Don't use a definition from a different statute — same word, different meaning
- When in doubt, query the corpus directly rather than relying on MCP tool
  defaults
