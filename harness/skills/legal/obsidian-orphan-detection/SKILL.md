# Obsidian Orphan Detection

## Overview

Orphaned notes — notes with no incoming or outgoing wikilinks — are lost
knowledge. This skill finds and fixes orphaned notes.

## Workflow

### Step 1: Find orphaned notes

    obsidian_list_orphans(folder_scope=SCOPE, limit=LIMIT)

### Step 2: Analyze each orphan

For each orphaned note, determine:
- What is the note about?
- What should it be linked to?
- What is the correct edge_type?

### Step 3: Connect the orphan

For each orphan, add wikilinks:
    obsidian_propose_link(from_note=ORPHAN_NOTE, to_note=TARGET_NOTE, edge_type=EDGE_TYPE, citation=CITATION)

### Step 4: Verify the connection

After connecting, verify the link is correct:
    obsidian_outgoing_links(note_path=ORPHAN_NOTE)
    obsidian_backlinks(note_path=ORPHAN_NOTE)

## Key patterns

### Orphaned definition notes

- Definition notes should be linked to the statute that defines the term
- Add wikilink: [[STATUTE]]

### Orphaned case notes

- Case notes should be linked to the statute they interpret
- Add wikilink: [[STATUTE]]
- Add wikilink: [[case_brief]] if applicable

### Orphaned remedy notes

- Remedy notes should be linked to the statute that provides the remedy
- Add wikilink: [[STATUTE]]
- Add wikilink: [[case]] if applicable

### Orphaned pattern notes

- Pattern notes should be linked to the cases and statutes they describe
- Add wikilink: [[case]] for each case
- Add wikilink: [[statute]] for each statute

## Pitfalls

- Don't connect orphans without analyzing them first
- Don't connect orphans without specifying the edge_type
- Don't connect orphans without verifying the connection
- Don't assume an orphan is truly orphaned — check the graph first
