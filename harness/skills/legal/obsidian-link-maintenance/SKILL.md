# Obsidian Link Maintenance

## Overview

Obsidian's power is in its wikilinks — the graph that connects notes. This skill
ensures wikilinks are properly maintained when writing to Obsidian.

## Workflow

### Step 1: Query the corpus for related notes

Before writing, query the corpus for related notes:
    GET http://localhost:8100/search_text?query=RELATED+statute+text&top_k=10

### Step 2: Search Obsidian for existing notes

Search Obsidian for existing notes that should be linked:
    obsidian_search_by_tag(tag=TAG)
    obsidian_search_by_frontmatter(field=FIELD, value=VALUE)

### Step 3: Write the note

Write the note to Obsidian:
    write_obsidian_note(subdir=SUBDIR, filename=FILENAME, content=CONTENT)

### Step 4: Add wikilinks

For each related note found, add a wikilink:
    obsidian_propose_link(from_note=FROM_NOTE, to_note=TO_NOTE, edge_type=EDGE_TYPE, citation=CITATION)

### Step 5: Verify the links

After writing, verify the links are correct:
    obsidian_outgoing_links(note_path=NOTE_PATH)
    obsidian_backlinks(note_path=NOTE_PATH)

## Key patterns

### Link types

- **authority** — the note is an authority for the target note
- **defined_by** — the note defines a term in the target note
- **cross_ref** — the note cross-references the target note
- **implements** — the note implements a rule in the target note
- **enforced_by** — the note is enforced by the target note
- **interpreted_by** — the note interprets the target note

### Linking to statutes

- Link to the statute note: [[15 USC 1681]]

### Linking to cases

### Linking to definitions

- Link to the definition note: [[definition_furnisher]]

## Pitfalls

- Don't write to Obsidian without adding wikilinks — the knowledge graph becomes fragmented
- Don't add wikilinks without verifying the target note exists — broken links
- Don't add wikilinks without specifying the edge_type — the graph loses meaning
- Don't assume Obsidian has the note — verify before linking
