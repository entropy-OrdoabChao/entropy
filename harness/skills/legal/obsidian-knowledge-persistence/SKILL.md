# Obsidian Knowledge Persistence

## Overview

Obsidian is the persistent knowledge graph — 84,953 markdown notes with
wikilinks between them. This skill writes discovered patterns to Obsidian
so they persist across sessions and can be cross-referenced.

## Where to write

### Definitions
- `obsidian_sync/definitions_learned/` — legal definitions discovered during
  research
- `obsidian_sync/definitions_learned/` — cross-referenced with [[statute]] links

### Remedy mappings
- `obsidian_sync/remedies/` — remedy mappings discovered during research
- `obsidian_sync/remedies/` — cross-referenced with [[statute]] links

### Patterns
- `obsidian_sync/patterns/` — recurring patterns discovered across cases
- `obsidian_sync/patterns/` — cross-referenced with [[case]] links

### Violations
- `obsidian_sync/violations/` — violations discovered during analysis
- `obsidian_sync/violations/` — cross-referenced with [[case]] links

### Learning notes
- `obsidian_sync/learning/` — lessons learned during research
- `obsidian_sync/learning/` — cross-referenced with [[statute]] links

## Workflow

### Step 1: Query the corpus for the pattern

    GET http://localhost:8100/search_text?query=PATTERN+statute+text&top_k=10

### Step 2: Write to Obsidian

Use `write_obsidian_note` to write the discovered pattern:
- subdir: appropriate directory (definitions_learned, remedies, patterns, etc.)
- filename: descriptive name with statute reference
- content: markdown with wikilinks to related notes

### Step 3: Add wikilinks

After writing, use `obsidian_propose_link` to add wikilinks:
- from_note: the note you just wrote
- to_note: related notes (statutes, cases, definitions)
- edge_type: authority, defined_by, cross_ref, etc.

### Step 4: Verify the write

Use `read_obsidian_note` to verify the note was written correctly.

## Key patterns

### Writing a definition

1. GET /lookup_term?term=TERM — find corpus occurrences
2. Write to obsidian_sync/definitions_learned/TERM.md
3. Add wikilink: [[STATUTE]]
4. Add wikilink: [[case]] if applicable

### Writing a remedy mapping

1. GET /search_text?query=STATUTE+remedy+damages&top_k=10
2. Write to obsidian_sync/remedies/STATUTE_remedies.md
3. Add wikilink: [[STATUTE]]
4. Add wikilink: [[case]] if applicable

### Writing a pattern

1. GET /search_text?query=PATTERN+across+cases+statute&top_k=10
2. Write to obsidian_sync/patterns/PATTERN.md
3. Add wikilink: [[case]] for each case
4. Add wikilink: [[statute]] for each statute

## Pitfalls

- Don't write to Obsidian without first querying the corpus
- Don't write without adding wikilinks — the knowledge graph becomes fragmented
- Don't write without verifying the write — always read it back
- Don't assume Obsidian has the definition — verify against the corpus
