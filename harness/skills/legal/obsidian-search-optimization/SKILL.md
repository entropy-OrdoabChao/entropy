# Obsidian Search Optimization

## Overview

Obsidian's wikilink graph is a knowledge graph — it connects notes by
relationship, not just by keyword. This skill uses the graph to find
related knowledge before querying the corpus.

## Workflow

### Step 1: Start with a known note

If you have a known note (e.g., a statute note), walk the graph:
    obsidian_graph_walk(start=START_NOTE, depth=2)

### Step 2: Search Obsidian by tag

Search Obsidian for notes with a specific tag:
    obsidian_search_by_tag(tag=TAG)

### Step 3: Search Obsidian by frontmatter

Search Obsidian for notes with a specific frontmatter field:
    obsidian_search_by_frontmatter(field=FIELD, value=VALUE)

### Step 4: Search Obsidian by keyword

Search Obsidian for notes containing a specific keyword:
    obsidian_search(query=QUERY)

### Step 5: Query the corpus for gaps

If the Obsidian graph doesn't have the answer, query the corpus:
    GET http://localhost:8100/search_text?query=QUERY&top_k=10

### Step 6: Write to Obsidian

If the corpus has something the Obsidian graph doesn't, write it:
    write_obsidian_note(subdir=SUBDIR, filename=FILENAME, content=CONTENT)

## Key patterns

### Graph walk for related statutes

1. Start with a known statute note: [[15 USC 1681]]
2. Walk the graph: obsidian_graph_walk(start=15 USC 1681, depth=2)
3. Find related statutes: [[15 USC 1681a]], [[15 USC 1681b]], etc.
4. Query the corpus for related statutes:
   GET /search_text?query=15 USC 1681 related statutes

### Graph walk for related cases

1. Start with a known case note: [[{{CASE_SLUG}}]]
2. Walk the graph: obsidian_graph_walk(start={{CASE_SLUG}}, depth=2)
3. Find related cases: [[{{CASE_SLUG}}]], [[{{CASE_SLUG}}]], etc.
4. Query the corpus for related cases:
   GET /search_text?query=related cases FCRA

### Graph walk for related definitions

1. Start with a known definition note: [[definition_furnisher]]
2. Walk the graph: obsidian_graph_walk(start=definition_furnisher, depth=2)
3. Find related definitions: [[definition_consumer]], [[definition_furnisher]], etc.
4. Query the corpus for related definitions:
   GET /lookup_term?term=furnisher

## Pitfalls

- Don't query the corpus without first checking the Obsidian graph
- Don't assume the Obsidian graph has the answer — verify against the corpus
- Don't query the corpus without specifying the query — broad queries return noise
- Don't assume the graph walk will find everything — it depends on the wikilinks
