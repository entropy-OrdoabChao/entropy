# Web Remedy Search

## Overview

The corpus is 35.6GB but not infinite. Some statutes, remedies, and case law
may not be indexed. This skill uses web search to fill gaps.

## Workflow

### Step 1: Check the corpus first

Before web searching, always query the corpus. If it returns results, use them.
Only web search if the corpus is silent.

### Step 2: Web search for the statute + remedy

    web_search(query="STATUTE remedy damages injunction")

Try multiple searches:
- STATUTE + "statutory damages"
- STATUTE + "injunctive relief"
- STATUTE + "attorney fees"
- STATUTE + "punitive damages"
- STATUTE + "enforcement provision"

### Step 3: Search for enforcement actions

    web_search(query="STATUTE enforcement action damages")

Look for:
- FTC enforcement actions
- CFPB enforcement actions
- State AG enforcement actions
- Private right of action cases

### Step 4: Search for case law

    web_search(query="STATUTE damages case law")

Look for:
- Circuit splits on remedies
- Supreme Court decisions
- Leading cases on damages caps

### Step 5: Cross-reference with corpus

If web search finds something the corpus doesn't have, note it as a potential
gap in the corpus. This may be worth flagging for corpus ingestion.

## Key patterns

### Federal enforcement agencies

- FTC: Federal Trade Commission enforcement
- CFPB: Consumer Financial Protection Bureau enforcement
- DOJ: Department of Justice enforcement
- State AGs: State Attorney General enforcement

### Private right of action

- Does the statute allow private suits?
- What remedies are available to private parties?
- Are there administrative prerequisites?

### Class action remedies

- Class-wide injunctive relief
- Class-wide damages
- Attorney fees for class counsel

## Pitfalls

- Don't rely solely on web search — the corpus is the primary source
- Don't trust random blog posts — look for official sources (gov, court, agency)
- Don't assume web search results are current — check dates
- Don't confuse proposed legislation with enacted law
- When web search finds something new, verify it against the actual statute text
